# 🛠 Config Converter

**یک ابزار پیشرفته و تحت وب برای تبدیل، ویرایش و شخصی‌سازی دسته‌جمعی کانفیگ‌های پروتکل‌های مختلف (V2Ray، Wireguard، Proton و...) با قابلیت دور زدن Deep Packet Inspection (DPI)**

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Live-brightgreen)](https://darknessshade.github.io/Config-Converter/)
[![License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

## 🌟 نمای کلی

Config Converter یک ابزار قدرتمند و کاملاً سمت کاربر (Client-side) است که به شما امکان می‌دهد:
- کانفیگ‌های پروتکل‌های **V2Ray** (شامل VLESS، VMess، Trojan، Shadowsocks) و **Wireguard** و **ProtonVPN** را به یکدیگر تبدیل کنید.
- به صورت دسته‌جمعی IP، پورت، نام و سایر پارامترهای کانفیگ‌ها را ویرایش کنید.
- برای دور زدن **DPI (Deep Packet Inspection)** در کشورهایی مانند ایران، چین و روسیه، **پکت‌های هرز (Junk Packets)** به کانفیگ‌های Wireguard اضافه کنید.

این پروژه تلفیقی از دو ابزار قدرتمند است و یک رابط کاربری یکپارچه برای تمام نیازهای تبدیل کانفیگ فراهم می‌کند.

## ✨ ویژگی‌های اصلی

### 🌐 پشتیبانی از پروتکل‌ها و فرمت‌ها
- **ورودی:** V2Ray (خام، Base64 یا لینک سابسکریپشن)، Wireguard (.conf)، ProtonVPN
- **خروجی:** V2Ray (با فرمت‌های دلخواه)، AmneziaWG (AWG)، Clash، Wiresock

### 🛡 قابلیت‌های ضد فیلترینگ (Anti-DPI)
- افزودن پارامترهای **پکت هرز (Junk Packets)** شامل `jc`، `jmin`، `jmax` به کانفیگ‌های Wireguard
- پشتیبانی از **پارامترهای آمونیا (Amnezia) 1.5** شامل `I1` تا `I5` برای ماسک کردن ترافیک
- تولید مقادیر تصادفی برای پارامترهای پکت هرز جهت سخت‌تر شدن شناسایی الگو

### ✏️ ابزارهای ویرایش دسته‌جمعی
- تغییر **آیپی یا دامنه** همه کانفیگ‌ها با یک مقدار جدید
- تغییر **پورت** همه کانفیگ‌ها
- تغییر **نام** کانفیگ‌ها به صورت یکسان یا الگودار
- ادغام کانفیگ‌های مختلف در یک فایل خروجی

### 🔧 امکانات تکمیلی
- **دریافت مستقیم از لینک سابسکریپشن** (بدون نیاز به دانلود فایل)
- **تشخیص خودکار کد کشور** و افزودن ایموجی پرچم برای سازماندهی بهتر
- **خروجی به صورت متن ساده یا فایل فشرده (Base64)**
- **نمایش QR کد** برای کانفیگ‌های نهایی
- **رابط کاربری دوزبانه** (فارسی/انگلیسی)

## 🚀 نحوه استفاده (راهنمای گام به گام)

1.  **ورود اطلاعات کانفیگ:**
    - می‌توانید به یکی از روش‌های زیر کانفیگ خود را وارد کنید:
        - چسباندن لینک **سابسکریپشن V2Ray**
        - چسباندن **متن خام** کانفیگ (در هر فرمت پشتیبانی شده)
        - آپلود فایل `.conf` یا `.txt` از سیستم خود
        - چسباندن کد **Base64** کانفیگ‌ها

2.  **انتخاب ویرایش‌های دلخواه (اختیاری):**
    - در بخش "تنظیمات ویرایش و ادغام"، در صورت نیاز:
        - آیپی/دامنه و پورت جدید خود را وارد کنید.
        - یک نام دلخواه برای جایگزینی نام‌های اصلی کانفیگ‌ها وارد کنید.

3.  **تنظیم فرمت خروجی و تبدیل:**
    - از بخش "پیکربندی فایل ورودی"، فرمت خروجی مورد نظر (مثلاً V2Ray، Amnezia، Clash) را انتخاب کنید.
    - **(برای Wireguard)** در بخش "تنظیمات پکت‌های هرز"، مقادیر `jc`، `jmin`، `jmax` را تنظیم کنید یا روی دکمه تصادفی کلیک کنید.
    - **(برای Amnezia 1.5)** پارامترهای `I1` تا `I5` را وارد کنید.
    - روی دکمه **تبدیل / Convert** کلیک کنید.

4.  **دریافت خروجی:**
    - نتایج به صورت متن در صفحه نمایش داده می‌شوند.
    - می‌توانید خروجی را کپی کرده یا به صورت فایل **دانلود** کنید.
    - برای کانفیگ اصلی، **QR کد** مربوطه نمایش داده می‌شود.

## 💡 نکات مهم و راهنمای کاربردی

- **برای دور زدن DPI در Wireguard:** حتماً فرمت خروجی `AmneziaWG` یا `Wiresock` را انتخاب کنید و پارامترهای پکت هرز را فعال کنید. مقادیر پیش‌فرض (`jc: 128, jmin: 1279, jmax: 1280`) معمولاً مؤثر هستند.
- **تغییر دسته‌جمعی IP:** اگر مجموعه‌ای از کانفیگ‌ها با IP یک سرور دارید، با وارد کردن IP جدید در بخش ویرایش، همه آن‌ها یکجا تغییر می‌کنند.
- **سابسکریپشن بیس (Base64):** لینک سابسکریپشن معمولاً باید با `https://` شروع شود تا ابزار بتواند آن را دریافت کند.

برای اجرای پروژه روی سیستم خودتان:

```bash

cd Config-Converter
python -m http.server 8000
```

سپس در مرورگر خود به آدرس `http://localhost:8000` بروید.
